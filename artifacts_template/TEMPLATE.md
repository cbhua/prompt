# Artifact 内容约束（可手动修改）

生成时先读这份文件；按用户修改后的内容执行。CSS 以当前 Prompt 项目原文件为准，不自行补充视觉默认值。

## Header

- 左侧只有 title；参考页和起始页为 Template。
- 右侧只有 Contents；点击弹出正文 H2/H3 的目录，选择后跳转。
- 沿用当前 Prompt 页面的原始 navbar CSS 与结构。
- Header 底部不加分割线。
- 不添加作者姓名、其他导航、logo、标签或主题开关。
- 正文中不重复放置目录。

## 正文

- 单页静态网站。
- 参考页展示技术报告常用的 H1、H2、H3、段落、列表、表格、图片、引用和代码格式。
- 参考内容来自 DeepSeek-V3 报告，保留出处，明确区分短引、摘要和示意代码。
- 实际 artifact 的内容、章节名称和数量由具体任务决定；参考内容不自动带入新 artifact。
- 不默认添加作者、日期、宣传性说明或其他任务没有要求的信息。参考页的原报告署名和来源用于引用归属。

## CSS 与字体

- 原始 Bootstrap、main.css 和 font-family.css 直接复制，不改写。
- css/report.css 是用户明确要求的例外：引用用大型装饰引号、细竖线与 Lucida Italic；引号和竖线使用 Header 标题红色 #bb3322，整个引用（含段落与 cite）为正文 1em；表头采用 Claudette 浅底色，表格采用 8px 圆角、内容自适应宽度并居中，图片和表格的 caption 样式一致，均与正文等宽、文字居中；cite 为正文字号、斜体、正常文字颜色。
- H1 下方使用与 Prompt 的 Scientific Writing 相同的 1px #888888 细线及 0.5em 底部留白，不改变字号或字重。
- 行间公式使用 p.font-serif[role="math"]，居中、1.2em、无序号；表格下方默认留出 1.5em 间距，可在 report.css 顶部调整。
- 表格使用 figure.report-table；figcaption.table-caption 独立于 setup-table 滚动容器，通过 aria-labelledby 关联 table。长表在内部横向滚动，caption 不随表格滚动。
- 不引入 Claudette 的其他组件或行 hover 效果；不另改标题大小、段落间距、代码字号、字重、引用背景、图片边框或打印主题。
- css/settings.css 默认留空，只有用户明确写入的值才覆盖源站。
- 字体、高亮和字体子集沿用当前项目；内容定稿后重新生成子集。
- 页面底部不显示“字体偏好与许可”区域，不默认添加 Footer。字体许可文件仍随包保留；底层 IPA 原字体替换支持保留，不提供页脚控件。

## 用户补充区

在这里添加你对具体 artifact 的限制，例如需要哪些章节、不需要哪些信息、是否保留某类示例。未填写的要求不由 agent 想当然补上。

## Markdown 正文骨架

```markdown
# 【标题】

【正文说明】

## 【章节】

【内容】

### 【必要的子章节】

【内容】
```

检查原文件哈希、正文各组件的计算样式、字体加载、目录交互和桌面/手机布局。只报告实际验证的项目。
