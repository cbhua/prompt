# 配置 macOS

请在这台 MacBook 上配置以下个人偏好。先检查 macOS 版本和当前设置，记录将要修改的原值，保留无关设置。优先使用当前系统支持的设置方式；可以通过命令行或系统设置界面操作。修改后验证实际效果，说明如何恢复。只执行必配项和已勾选的可选项，未勾选项保持原样。

## 必配项

1. **Caps Lock 改为 Control**：在“系统设置 → 键盘 → 键盘快捷键 → 修饰键”中，将内置键盘的 Caps Lock 功能设为 Control；原有 Control 仍为 Control，其他修饰键保持原样。这是单向映射，不是交换两个键。检查已连接的外接键盘并应用相同设置，说明修饰键设置可能按键盘分别保存。使用持久设置，不用仅本次登录生效的临时映射。[Apple 说明](https://support.apple.com/guide/mac-help/change-the-behavior-of-the-modifier-keys-mchlp1011/mac)
2. **Finder 始终显示隐藏文件和所有扩展名**：持久启用隐藏文件显示，以及 Finder 设置中的“显示所有文件扩展名”。重新打开 Finder 后验证点开头的文件和文件扩展名均可见。[扩展名设置](https://support.apple.com/guide/mac-help/show-or-hide-filename-extensions-mchlp2304/mac)
3. **截图保存到下载目录**：将系统截图默认保存位置设为当前用户的 `~/Downloads`（Finder 中的“下载”目录），不是新建 `Download` 文件夹。可通过 `Cmd+Shift+5 → 选项 → 存储到 → 其他位置` 设置。保留其他截图选项，验证新截图实际保存到该目录。[Apple 说明](https://support.apple.com/102646)

## 可选项

以下是候选偏好，并非旧电脑的配置快照。我会按个人习惯修改取值、勾选需要的条目或删除不需要的条目；执行 agent 只应用 `[x]` 条目。

### 键盘与输入

- [ ] 按键重复速度设为最快，重复前延迟设为最短。
- [ ] 长按字母时重复输入，关闭长按弹出重音字符菜单；验证编辑器中的 hjkl 连续移动。
- [ ] 关闭自动纠正、自动首字母大写、双空格插入句号，以及智能引号和智能破折号；保留输入法本身的候选功能。
- [ ] F1–F12 默认作为标准功能键，按 Fn 才调整亮度和音量。
- [ ] 输入法只保留 ABC 和简体拼音，使用 `Control+Space` 切换，检查与终端快捷键是否冲突。

### Finder

- [ ] 显示路径栏和状态栏。
- [ ] 默认采用列表视图，排序时文件夹在前。
- [ ] 新 Finder 窗口默认打开个人主目录。
- [ ] 侧边栏加入主目录、Downloads、Documents 和 `~/Github`（目录存在时）。
- [ ] 搜索默认限定在当前文件夹。
- [ ] 关闭修改扩展名时的确认提示。

### Dock 与窗口

- [ ] Dock 自动隐藏，保留默认动画速度。
- [ ] Dock 放在屏幕底部，图标大小设为 40，不启用放大。
- [ ] Dock 不显示最近使用的应用。
- [ ] 关闭根据最近使用情况自动重新排列 Spaces。
- [ ] 关闭 Stage Manager（台前调度）。

### 触控板与鼠标

- [ ] 开启轻点来点按。
- [ ] 双指点按作为辅助点按（右键）。
- [ ] 在辅助功能中开启触控板“三指拖移”。
- [ ] 触控板保留自然滚动；外接鼠标的滚动方向按实际驱动单独配置。

### 外观、截图与日常使用

- [ ] 系统外观固定为深色，不随时间自动切换。
- [ ] 截图使用 PNG 格式。
- [ ] 关闭截图后的浮动缩略图，让文件更快落盘。
- [ ] 菜单栏时钟显示日期和星期，使用 24 小时制。
- [ ] 关闭自动亮度和 True Tone，以便查看稳定的屏幕颜色。
- [ ] 电池菜单显示百分比。

## 验证与交付

逐项报告已修改、原本符合、无法自动完成的设置，并保留原值供恢复。仅在必要时重新打开 Finder、Dock 或相关应用；需要退出登录或重启时说明，不自动中断当前工作。若缺少界面控制能力或系统要求用户操作，完成其余项目并给出具体操作路径，不把未执行的项目报告为完成。
